What do these columns mean?
dtype
The kind of data: float or int are numbers, str is text, datetime is dates.
missing
How many cells are empty.
unique
How many different values appear.
mean
The average. Extreme values can pull it a long way.
median
The middle value when sorted. Extreme values barely move it.
std
Standard deviation: how far values typically sit from the mean.
min and max
The smallest and largest values.
outliers
Values unusually far from the middle 50% of the column (the 1.5 IQR rule). They can be errors or real events, so check before removing them.
top
The most common value in a text column.

How is the score worked out?

Scores run from 0 (no relationship) to 1 (very strong). The method depends on the two columns:

Correlation
Two number or date columns: do they rise and fall together in a straight line?
Group differences
A number and a text column: do the groups have clearly different averages? (Correlation ratio.)
Category match
Two text columns: do certain values tend to appear together? (Cramér's V.)
Data quality
With no goal, each column is scored on how complete and how varied it is. That shows what is usable, not what matters.

Related does not mean one column causes the other.
